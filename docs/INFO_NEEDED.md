# Information needed from the site (before Phase 2)

Send this list to Yousif. The answers decide the connection route and let the
placeholder profiles become real.

## 1. ComAp controller
- [ ] Exact model (photo of the controller front + the model name)
- [ ] Does the screen show PV/solar and battery values, or only the generator(s)?
- [ ] Communication module fitted? (CM-Ethernet, CM-4G-GPS, built-in Ethernet)
- [ ] Is WebSupervisor already set up for the plant? (who owns the account)
- [ ] The ComAp **communication guide / Modbus register map** for this model
      (ComAp support, or export it from InteliConfig)

## 2. PV inverters

## 3. Battery (if any)
- [ ] Brand/model of the battery (PCS + BMS)
- [ ] How it's monitored (own portal, through the inverter, through ComAp?)

## 4. Network & site

- [ ] IP addresses of the controller and logger (once on the network)
- [ ] Is there a technician/electrician on site who can help install a small box
